# 🧠 Mental Health Support — Demo

A **frontend demo** for Mental Health Support, built with **HTML, Tailwind CSS, and Chart.js**.  
Hackathon submission for **PKP Mumbai Hack 2025**. 🚀

## ✨ Features

- **Login / Demo Login** (no backend required)  
- **Mood Tracking** with tips and actions  
- **Journal Entries** saved temporarily in browser  
- **Appointment Booking** (frontend simulation)  
- **SOS & Helpline Quick Access**  
- **Progress Visualization** with interactive charts
